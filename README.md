## ⭐ Top 5 Concepts Explained

### 1. JavaScript
JavaScript makes websites interactive and functional. It handles logic, calculations, events, data manipulation and communication with APIs. React itself relies heavily on JavaScript concepts.

**Key Words:** Logic, Interaction, Events, Data, Functionality

### 2. Functions
Functions are reusable blocks of code that perform specific tasks. They help organise code and handle calculations, events, API calls and application logic.

**Key Words:** Reusable, Parameters, Return, Execution, Logic

### 3. Web Applications
Web applications are software programs accessed through web browsers. They combine user interfaces, functionality, data and sometimes backend services to provide useful features.

**Key Words:** Frontend, Backend, Database, Functionality, Users

### 4. CSS
CSS controls the visual appearance of websites. It manages colours, fonts, spacing, layouts, animations and responsive designs.

**Key Words:** Styling, Layout, Colours, Animation, Responsiveness

### 5. React
React is a JavaScript library used to build interactive user interfaces. It helps developers create reusable components and manage changing application data through state and props.

**Key Words:** Components, State, Props, Reusability, Rendering
